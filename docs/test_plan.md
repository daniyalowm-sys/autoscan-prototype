# План проверки MVP «АвтоСкан»

## Этап 1. Стендовая проверка программного конвейера

- металлические поверхности с чистым участком, водой и моторным маслом;
- не менее трёх направлений подсветки и трёх расстояний до камеры;
- не менее 50 кадров;
- ручная разметка областей и сравнение эвристического алгоритма с разметкой;
- результат: подтверждение полного цикла «кадр → маска → подтверждение → отчёт».

Синтетические изображения используются только для проверки запуска программы и не
включаются в расчёт точности.

## Этап 2. Сбор данных на пилотной площадке

- не менее 100 автомобилей;
- не менее 1 500 изображений;
- обезличивание государственных номеров и персональных данных при случайном попадании;
- фиксация типа автомобиля, условий освещения и решения механика;
- отдельная маркировка свежих следов, старых загрязнений, коррозии и чистых участков.

## Этап 3. Разработка и валидация модели

- разделение данных по автомобилям, а не отдельным кадрам;
- обучение — не более 70%, валидация — 15%, отложенный тест — не менее 15%;
- базовая линия: эвристический алгоритм OpenCV;
- основной вариант: компактная модель сегментации после накопления данных;
- целевые показатели на отложенной выборке: `recall >= 75%`, `precision >= 70%`;
- отдельно публикуется количество ложных срабатываний на один осмотр.

## Этап 4. Пилотные испытания комплекса

- не менее 50 автомобилей;
- время одного осмотра — не более 7 минут;
- автономная работа — не менее 60 минут;
- высота тележки — не более 90 мм;
- работоспособность аварийной остановки и ручного извлечения;
- сохранение кадров и формирование фотоотчёта без потери данных;
- анкета механика по удобству управления и полезности отчёта.

## Правило интерпретации

Алгоритм не определяет причину неисправности и вид жидкости. Положительный результат
означает только наличие участка, который должен повторно проверить механик.
